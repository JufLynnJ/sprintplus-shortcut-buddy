# Sprintplus Master

kan je een webpagina maken waarbij een leerling de sneltoetsen van sprintplus kan oefenen. Kan je aantonen wat ie moet doen en als hij de sneltoets juiost intypt krijgt hij een coole tekening en een groen vinkje. Bij een fout een jammerend beeld met een zonnebril en nog een poging laten doen bij 3sde poging een chatbotmannetje laten voor zeggen.  https://www.jabblasoft.com/files/helpfiles/sprintplus3_nl_webhelp/re_sneltoetsen.html
